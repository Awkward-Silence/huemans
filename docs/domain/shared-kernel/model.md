# Shared Kernel

**Generated with**: ddd-modeling 0.4.0-alpha

Types shared across bounded contexts. Changes to this model affect
all BCs that reference these types — coordinate before modifying.

## Value Objects

| Name | Construction Rule | Invalid States | Used by |
|---|---|---|---|
| EventId | UUIDv7, generated by the Event context when an event is created | not a valid UUIDv7 | Event, Participation, Color Distribution, icebreaker selection |
| AttendeeId | UUIDv7, generated by Participation when an attendee joins | not a valid UUIDv7 | Participation, Color Distribution |
| Trait | One of the 33 catalog traits (closed list, defined in `api/src/Shared/Domain/ValueObject/Trait.ts`) | any value outside the list | Catalog, Participation, Color Distribution, icebreaker selection |
| Color | One of exactly 4 group colors: amber, coral, teal, violet (closed set). That order is fixed: it breaks assignment ties and orders every per-color list | any value outside the 4 colors | Color Distribution (assignment, distribution), Room (group counts), Night Icebreaker (meeting spot per color) |
| PersonalityType | One of exactly 4 types: explorer, connector, planner, dreamer (closed set) | any value outside the 4 types | Catalog (profiles, trait-type mapping), Color Distribution (assignment, group balancing) |
